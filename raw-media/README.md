# raw-media

Drop original photos and videos here. Do not rename slots; extra files are fine.

- brand/     square logo mark (if any)
- home/      hero video + poster, crew photo, service photos (garage, blinds), home before/after pair
- projects/<service>-NN/   one folder per job:
    before.jpg, after.jpg   same angle (optional)
    cover.jpg               main shot (or cover.mp4 for a clip, max 8s)
    1.jpg 2.jpg 3.jpg       detail shots (optional)
    info.txt                fill in real details only; leave blank if unknown

Copy a project folder and bump the number for more jobs (garage-doors-03, ...).
Missing pieces are fine. They get flagged, not guessed.
